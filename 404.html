404 - FILE NOT FOUND
Система не может найти указанный файл или директорию.
server@portfolio:~$ locate requested_page
ERROR: No such file or directory
Возможные причины:
  • Файл был перемещен или удален
  • В адресе есть опечатка
  • Ссылка устарела
  • Ресурс временно недоступен
Рекомендуемые действия:
  • Проверьте правильность введенного URL
  • Вернитесь на главную страницу
  • Воспользуйтесь навигацией выше для перехода к существующим разделам
